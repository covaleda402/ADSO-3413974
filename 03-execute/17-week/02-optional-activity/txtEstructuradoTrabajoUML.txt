Instrumento de Recolección de Información
Proyecto

Sistema de Toma de Asistencia para el SENA

Técnica utilizada

Entrevista simulada

Objetivo

Identificar las necesidades y requerimientos funcionales de un sistema que permita optimizar el proceso de registro de asistencia de los aprendices del SENA.

Entrevista simulada

Nota: Debido a que esta actividad corresponde a un ejercicio académico, se realizó una simulación del proceso de levantamiento de requisitos. El siguiente diálogo representa una interacción entre el analista y el cliente (Instructor del SENA) con el propósito de identificar las necesidades del sistema.

Participantes

Analista: Estudiante ADSO

Cliente: Instructor del SENA

Desarrollo de la entrevista

Analista: ¿Cómo realiza actualmente la toma de asistencia?

Instructor: Ingreso al sistema institucional y debo registrar la asistencia de cada aprendiz de manera individual.

Analista: ¿Qué inconvenientes presenta el proceso actual?

Instructor: El registro de asistencia consume bastante tiempo, especialmente cuando el grupo tiene un número elevado de aprendices.

Analista: ¿Qué mejoras considera necesarias?

Instructor: Me gustaría visualizar todos los aprendices de una ficha en una sola pantalla para registrar la asistencia de manera más rápida.

Analista: ¿Qué información debe almacenar el sistema?

Instructor: La fecha, la hora, la ficha, el aprendiz, el estado de asistencia y el instructor que realizó el registro.

Analista: ¿Es necesario modificar una asistencia después de registrarla?

Instructor: Sí. En algunos casos es necesario corregir errores o justificar inasistencias.

Analista: ¿Quiénes utilizarán el sistema?

Instructor: Principalmente los instructores.

Analista: ¿Qué consultas o reportes considera importantes?

Instructor: Consultar la asistencia por ficha, por aprendiz o por fecha, además de generar reportes cuando sea necesario.

Análisis de la información obtenida

A partir de la entrevista simulada se identificó que el principal problema del proceso actual es el tiempo requerido para registrar la asistencia de manera individual. Como solución, se propone un sistema que permita visualizar todos los aprendices de una ficha en una sola pantalla, agilizando el registro, la consulta y la modificación de las asistencias, además de facilitar la generación de reportes.

Requisitos Funcionales
Código	Requisito
RF01	El sistema permitirá al instructor iniciar sesión.
RF02	El sistema permitirá seleccionar una ficha de formación.
RF03	El sistema mostrará el listado de aprendices pertenecientes a la ficha seleccionada.
RF04	El instructor podrá registrar la asistencia de todos los aprendices desde una sola pantalla.
RF05	El sistema permitirá modificar un registro de asistencia previamente almacenado.
RF06	El sistema registrará automáticamente la fecha y la hora de la asistencia.
RF07	El instructor podrá consultar el historial de asistencias por ficha, aprendiz o fecha.
RF08	El sistema permitirá generar reportes de asistencia.
Casos de uso identificados

Con base en los requisitos funcionales se identifican los siguientes casos de uso:

CU01. Iniciar sesión.
CU02. Seleccionar ficha.
CU03. Visualizar aprendices.
CU04. Registrar asistencia.
CU05. Modificar asistencia.
CU06. Consultar asistencia.
CU07. Generar reporte.
CU08. Cerrar sesión.
CU09. Consultar mi asistencia (Aprendiz).
Clases identificadas

Del análisis de los requisitos se identifican las siguientes clases principales:
